## Quick start (local)

1. Create a `.env` file in the project root with at least:

```
DATABASE_URL=sqlite:///./voice_agent.db
jwt_secret_key=replace_with_a_secure_random_value
```

2. Install dependencies (recommend using a virtualenv):

```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1   # (PowerShell)
python -m pip install -r requirements.txt
```

3. Run the app with uvicorn:

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

4. Open http://localhost:8000/docs for the autogenerated Swagger UI.

## Database

- On app startup, `Base.metadata.create_all(bind=engine)` in [app/main.py](</D:/Rayyan/Voice - Agent/voice-agent.worktrees/update-readme-with-file-details/app/main.py>) will create the tables defined in [app/db/models.py](</D:/Rayyan/Voice - Agent/voice-agent.worktrees/update-readme-with-file-details/app/db/models.py>).
- The default instructions above use a local SQLite DB. For production, set `DATABASE_URL` to a Postgres URL (requirements include `psycopg2-binary`).
